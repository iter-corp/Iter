================================================================
COIL — FIREBASE BACKEND IMPLEMENTATION PLAN
Split between 2 developers (Dev A + Dev B)
================================================================

SHARED SETUP (do together, ONCE, before splitting)
----------------------------------------------------------------
1. Create Firebase project at console.firebase.google.com (name: coil-app).
2. Enable: Authentication, Firestore, Storage, Cloud Messaging,
   Realtime Database, Cloud Functions, Cloud Translate API.
3. Install tools:
     npm i -g firebase-tools
     dart pub global activate flutterfire_cli
4. In frontend/ run:
     flutterfire configure
   -> generates lib/firebase_options.dart
5. Add packages to pubspec.yaml:
     firebase_core, firebase_auth, cloud_firestore,
     firebase_storage, firebase_messaging, firebase_database,
     cloud_functions, image_picker, cached_network_image,
     flutter_riverpod (already present)
6. Initialize in main.dart:
     await Firebase.initializeApp(options: DefaultFirebaseOptions...)
7. Create folder structure:
     src/services/    (Firebase service classes)
     src/providers/   (Riverpod providers)
     src/models/      (data classes - extend existing models)
     functions/       (Cloud Functions project, `firebase init functions`)
8. Agree on Firestore collection names (see schema below).
9. Create a shared git branch `backend` and both pull from it.

================================================================
FIRESTORE SCHEMA (both devs must follow this exactly)
================================================================
users/{uid}
  username, handle, bio, avatarUrl, coverUrl, gender,
  followersCount, followingCount, postsCount, createdAt, fcmTokens[]
users/{uid}/followers/{followerUid}
users/{uid}/following/{followingUid}

posts/{postId}
  authorUid, caption, imageUrls[], isPrivate,
  likesCount, commentsCount, createdAt
posts/{postId}/likes/{uid}
posts/{postId}/comments/{commentId}

stories/{storyId}
  authorUid, mediaUrl, type, createdAt, expiresAt

feeds/{uid}/timeline/{postId}

chats/{chatId}  (chatId = sorted uid pair "uidA_uidB")
  participants[], lastMessage, lastTime, unread{}
chats/{chatId}/messages/{msgId}

notifications/{uid}/items/{notifId}
  type, actorUid, targetId, read, createdAt

events/{eventId}
  title, description, imageUrls[], location, phone, email,
  hostUid, startsAt
events/{eventId}/attendees/{uid}

liveStreams/{streamId}
  hostUid, title, token, isActive, viewersCount, startedAt

Realtime DB:
  presence/{uid}         (online/offline + lastSeen)
  typing/{chatId}/{uid}  (true/false)

Storage paths:
  avatars/{uid}.jpg
  covers/{uid}.jpg
  posts/{uid}/{postId}/{i}.jpg
  stories/{uid}/{storyId}.jpg
  events/{eventId}/{i}.jpg
  chats/{chatId}/{msgId}.jpg

---- PHASE B2: NOTIFICATIONS ----
Wire:
  - notification_screen.dart -> StreamProvider(notifications/{uid}/items)
  - notification_tile.dart   -> handle CTA (Follow Back etc.)

Files:

    getNotifications(), markRead(id), getUnreadCount()

    initFcm() -> request permission + save token to users/{uid}.fcmTokens
    handle foreground + background messages

Cloud Functions:
  sendPushOnNotificationCreate  (listens on notifications/{uid}/items/{id})
    -> reads user's fcmTokens -> sends via admin.messaging()

---- PHASE B3: MESSAGING (1-on-1) ----
Wire:
  - message_screen.dart   -> StreamProvider(chats where participants contains uid)
  - chat_screen.dart      -> StreamProvider(chats/{chatId}/messages)

  - request_screen.dart   -> filtered inbox (non-followers)

Files:
  src/services/chat_service.dart
    openChat(otherUid) -> creates chatId (sorted uids)
    sendMessage(chatId, text, imageFile?)
    markSeen(chatId), streamMessages(chatId),
    streamInbox(), streamRequests()
  src/services/presence_service.dart  (Realtime DB)
    setOnline(), listenPresence(uid)
  src/services/typing_service.dart    (Realtime DB)
    setTyping(chatId, bool), listenTyping(chatId, otherUid)

Cloud Functions:
  onMessageCreate -> update chat summary (lastMessage, lastTime, unread++)
                     + create notification for receiver
                     + send FCM push

---- PHASE B5: LIVE STREAMING ----
